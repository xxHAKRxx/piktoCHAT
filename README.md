# piktoCHAT
A simple live chat website meant to practice using websockets with Django Channels.

This django app was made using this tutorial I found online: https://channels.readthedocs.io/en/latest/tutorial/index.html

Unfortunately the app currently doesn't work right now, something to do with redis. I did try to use the docker desktop app that the tutorial said to download, but it kept complaining that my PC did not have virtualization support for some reason.
